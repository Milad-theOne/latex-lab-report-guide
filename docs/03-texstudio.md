## 🎯 در این درس چه یاد می‌گیریم؟

در پایان این درس می‌توانید:

- بخش‌های مختلف TeXstudio را شناسایی کنید.

- تفاوت فایل `.tex` و `.pdf` را توضیح دهید.

## ۱. TeXstudio دقیقاً چیست؟

TeXstudio یک محیط ویرایش و توسعه LaTeX است.

به زبان ساده، TeXstudio برنامه‌ای است که در آن کدهای LaTeX را می‌نویسیم، فایل‌ها را مدیریت می‌کنیم و نتیجه پردازش را مشاهده می‌کنیم.

اما یک نکته مهم وجود دارد:

**TeXstudio خودش موتور LaTeX نیست.**

برای تولید PDF، این نرم‌افزار از ابزارهایی مانند XeLaTeX استفاده می‌کند که همراه توزیع‌هایی مثل MiKTeX یا TeX Live نصب شده‌اند.

روند کلی:

```text
┌──────────────────────┐
│  TeXstudio           │
│  نوشتن فایل main.tex │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  XeLaTeX             │
│  پردازش کدها         │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  main.pdf            │
│  گزارش نهایی         │
└──────────────────────┘
```

## ۲. آشنایی با بخش‌های محیط TeXstudio

پس از باز کردن TeXstudio، چند بخش اصلی مشاهده می‌کنید.

چیدمان دقیق بخش‌ها ممکن است بسته به نسخه برنامه و تنظیمات شما کمی متفاوت باشد.

### ۲.۱. نوار منو (Menu Bar)

در قسمت بالای برنامه، منوهایی مانند موارد زیر وجود دارند:

| منو | کاربرد |
|---|---|
| File | ایجاد، باز کردن و ذخیره فایل |
| Edit | ویرایش، جست‌وجو و جایگزینی متن |
| Tools | اجرای ابزارهای پردازش |
| LaTeX | درج دستورها و ساختارهای LaTeX |
| Math | درج نمادها و ساختارهای ریاضی |
| Options | تنظیمات برنامه |
| Help | راهنما و اطلاعات نرم‌افزار |

فعلاً مهم‌ترین منوهای ما `File`، `Tools` و `Options` هستند.

### ۲.۲. نوار ابزار (Toolbar)

در زیر نوار منو معمولاً تعدادی دکمه وجود دارد.

دکمه‌های پرکاربرد:

- **New:** ایجاد فایل جدید
- **Open:** باز کردن فایل موجود
- **Save:** ذخیره تغییرات
- **Build & View:** پردازش سند و نمایش خروجی
- **View PDF:** مشاهده فایل PDF

ممکن است بعضی دکمه‌ها در نسخه‌های مختلف ظاهر متفاوتی داشته باشند.

### ۲.۳. ویرایشگر کد (Editor)

این بخش مهم‌ترین قسمت TeXstudio است.

در این قسمت فایل‌هایی با پسوند `.tex` را ویرایش می‌کنیم.

برای مثال:

```latex
\section{مقدمه}
این متن مقدمه گزارش است.
```

TeXstudio معمولاً دستورها، متن‌ها و برخی ساختارهای LaTeX را با رنگ‌های متفاوت نمایش می‌دهد.

این قابلیت را **Syntax Highlighting** می‌نامند.

هدف آن آسان‌تر کردن خواندن کد است.

### ۲.۴. نمایشگر PDF

TeXstudio دارای نمایشگر داخلی PDF است.

پس از پردازش موفق سند، می‌توانید نتیجه را در همین برنامه مشاهده کنید.

در بسیاری از چیدمان‌ها:

- سمت چپ: کد LaTeX
- سمت راست: خروجی PDF

این چیدمان برای گزارش‌نویسی بسیار کاربردی است؛ چون می‌توانید هم‌زمان کد و نتیجه را ببینید.

### ۲.۵. پنل ساختار سند (Structure)

در این قسمت می‌توانید ساختار گزارش را مشاهده کنید.

مثلاً اگر سند شما شامل بخش‌های زیر باشد:

```latex
\section{مقدمه}
\section{هدف آزمایش}
\section{مراحل انجام کار}
\section{نتیجه‌گیری}
```

TeXstudio می‌تواند عنوان این بخش‌ها را در پنل ساختار نمایش دهد.

با کلیک روی هر عنوان، سریع‌تر به محل مربوط در کد می‌روید.

### ۲.۶. پنل پیام‌ها و خطاها

در پایین محیط برنامه معمولاً بخشی برای نمایش اطلاعات پردازش وجود دارد.

این قسمت ممکن است شامل موارد زیر باشد:

- پیام‌های اجرای ابزارها
- خطاهای LaTeX
- هشدارها
- اطلاعات فایل‌های پردازش‌شده

اگر PDF ساخته نشد، این بخش اولین جایی است که باید بررسی کنید.

---

## ۳. ساخت یک پروژه جدید

برای تمرین، یک پروژه جدید می‌سازیم.

### مرحله اول: ایجاد پوشه

در ویندوز یا اوبونتو، پوشه‌ای با نام زیر بسازید:

`TeXstudioPractice`

بهتر است برای هر گزارش یک پوشه جداگانه داشته باشید.

### مرحله دوم: ساخت فایل

1. TeXstudio را باز کنید.
2. از منوی `File` گزینه `New` را انتخاب کنید.
3. فایل خالی جدید ایجاد می‌شود.

### مرحله سوم: وارد کردن کد

کد زیر را وارد کنید:

```latex
\documentclass[12pt,a4paper]{article}

\usepackage{xepersian}

% این دو فونت را متناسب با سیستم خود تنظیم کنید.
\settextfont{Tahoma}
\setlatintextfont{Times New Roman}

\begin{document}

\section{آشنایی با تک‌استودیو}

این اولین تمرین من در محیط TeXstudio است.

\section{هدف تمرین}

در این تمرین یاد می‌گیریم چگونه فایل بسازیم،
آن را ذخیره کنیم و خروجی PDF بگیریم.

\end{document}
```

**نکته برای کاربران اوبونتو:** اگر فونت Tahoma روی سیستم نصب نیست، این دو خط را جایگزین کنید:

```latex
\settextfont{Amiri}
\setlatintextfont{Latin Modern Roman}
```

### مرحله چهارم: ذخیره فایل

از منوی `File` گزینه `Save As` را انتخاب کنید.

فایل را با نام زیر ذخیره کنید:

`main.tex`

ساختار پوشه شما:

```text
TeXstudioPractice/
└── main.tex
```

## ۴. تفاوت فایل TEX و PDF

یکی از سؤال‌های رایج مبتدیان این است که چرا بعد از پردازش، چند فایل ایجاد می‌شود.

### فایل TEX

فایل `.tex` حاوی کد منبع گزارش است.

برای مثال:

`main.tex`

این فایل قابل ویرایش است و برای اصلاح گزارش به آن نیاز داریم.

### فایل PDF

فایل `.pdf` خروجی پردازش‌شده و قابل مشاهده گزارش است.

برای مثال:

`main.pdf`

این فایل معمولاً برای مطالعه، چاپ یا تحویل گزارش استفاده می‌شود.

**نکته مهم:** فایل PDF جایگزین فایل TEX نیست. اگر استاد فایل‌های منبع را درخواست کرده باشد، باید فایل TEX و سایر فایل‌های لازم پروژه را هم تحویل دهید.

---

## ۵. تنظیم کامپایلر XeLaTeX

برای پردازش اسناد فارسی این مجموعه، از XeLaTeX استفاده می‌کنیم.

مراحل:

1. از منوی `Options` وارد `Configure TeXstudio` شوید.
2. بخش `Build` را انتخاب کنید.
3. در قسمت `Default Compiler` گزینه `XeLaTeX` را انتخاب کنید.
4. تنظیمات را ذخیره کنید.

### چرا XeLaTeX؟

زیرا برای کار با متن Unicode، فونت‌های سیستم و اسناد فارسی مناسب است.

بسته XePersian نیز در این آموزش همراه XeLaTeX استفاده می‌شود.

### تفاوت Build و Compiler

**Compiler:** ابزار پردازشی است که فایل TEX را پردازش می‌کند؛ مثل XeLaTeX.

**Build:** فرایندی است که با اجرای ابزارهای تنظیم‌شده، خروجی سند را تولید می‌کند.

بنابراین وقتی Build را اجرا می‌کنیم، TeXstudio بر اساس تنظیمات، موتور مناسب را فراخوانی می‌کند.

---

## ۶. اجرای سند و مشاهده PDF

بعد از ذخیره `main.tex`:

1. مطمئن شوید XeLaTeX انتخاب شده است.
2. دکمه `Build & View` را بزنید.
3. یا از کلید `F5` استفاده کنید.
4. منتظر پایان پردازش بمانید.

اگر همه‌چیز درست باشد، فایل `main.pdf` ساخته می‌شود.

### اگر PDF نمایش داده نشد

ابتدا بررسی کنید آیا خود فایل PDF در پوشه پروژه ایجاد شده است یا خیر.

اگر فایل وجود دارد ولی نمایش داده نمی‌شود، ممکن است مشکل از نمایشگر PDF یا چیدمان پنجره‌ها باشد.

اگر فایل اصلاً ایجاد نشده، باید پیام‌های پردازش را بررسی کنید.

---

## ۷. مفهوم خطا و هشدار

در LaTeX دو نوع پیام مهم وجود دارد.

### Error — خطا

خطا معمولاً نشان می‌دهد بخشی از کد یا تنظیمات مشکل دارد.

برای مثال:

```text
! LaTeX Error: File `xepersian.sty' not found.
```

این خطا می‌گوید بسته XePersian پیدا نشده است.

یا:

```text
! Undefined control sequence.
```

این پیام معمولاً به استفاده از دستوری ناشناخته یا اشتباه تایپی اشاره دارد.

### Warning — هشدار

هشدار همیشه مانع تولید PDF نمی‌شود.

برای مثال:

```text
LaTeX Warning: Reference `fig:test' undefined.
```

این پیام نشان می‌دهد یک ارجاع هنوز قابل شناسایی نیست.

گاهی با اجرای دوباره پردازش مشکل برطرف می‌شود و گاهی باید برچسب یا ارجاع را اصلاح کنید.

---

## ۸. چگونه خطاهای LaTeX را پیدا کنیم؟

فرض کنید اشتباهاً چنین کدی نوشته‌اید:

```latex
\secton{مقدمه}
```

دستور صحیح:

```latex
\section{مقدمه}
```

اگر دستور اشتباه را اجرا کنید، احتمالاً پیام `Undefined control sequence` مشاهده می‌کنید.

### روش پیشنهادی رفع خطا

1. پنل پیام‌ها و خطاها را باز کنید.
2. اولین خطای اصلی را پیدا کنید.
3. شماره خط یا محل اشاره‌شده را بررسی کنید.
4. کد را اصلاح کنید.
5. فایل را ذخیره کنید.
6. دوباره Build را اجرا کنید.

**نکته:** همیشه از اولین خطای اصلی شروع کنید؛ زیرا یک اشتباه ممکن است باعث چندین پیام خطای بعدی شود.

---

## ۹. آشنایی با کامنت‌ها (Comments)

در LaTeX از علامت `%` برای نوشتن توضیحات استفاده می‌کنیم.

مثال:

```latex
% این خط فقط یک توضیح است.
\section{مقدمه}
```

متن بعد از `%` تا انتهای همان خط، به‌عنوان توضیح در نظر گرفته می‌شود و در خروجی نمایش داده نمی‌شود.

مثال:

```latex
این متن نمایش داده می‌شود. % توضیح برای نویسنده
```

### کامنت‌ها چه کاربردی دارند؟

- توضیح دادن قسمت‌های مختلف کد
- غیرفعال کردن موقت یک خط
- مشخص کردن بخش‌هایی که باید بعداً اصلاح شوند

در گزارش نهایی بهتر است توضیحات غیرضروری و آزمایشی حذف شوند.

---

## ۱۰. قابلیت تکمیل خودکار کد

TeXstudio هنگام تایپ برخی دستورها پیشنهادهایی نمایش می‌دهد.

برای مثال وقتی شروع به تایپ می‌کنید:

```latex
\sec
```

ممکن است دستور زیر پیشنهاد شود:

```latex
\section{}
```

این قابلیت را **Auto Completion** می‌نامند.

مزیت‌های آن:

- کاهش اشتباهات تایپی
- افزایش سرعت نوشتن
- کمک به یادگیری دستورهای LaTeX

با گذشت زمان، بسیاری از دستورها را از طریق همین پیشنهادها یاد می‌گیرید.

---

## ۱۱. جست‌وجو و جایگزینی متن

در گزارش‌های طولانی، پیدا کردن یک کلمه یا عبارت اهمیت زیادی دارد.

### جست‌وجو

معمولاً با کلیدهای زیر می‌توانید جست‌وجو کنید:

`Ctrl + F`

برای مثال عبارت «هدف آزمایش» را جست‌وجو کنید.

### جایگزینی

در TeXstudio می‌توانید از قابلیت Find and Replace برای جایگزین کردن متن استفاده کنید.

این قابلیت برای تغییر عبارت‌های تکراری مفید است.

مثلاً اگر نام یک آزمایش چندین بار در گزارش نوشته شده باشد، می‌توانید آن را یکجا اصلاح کنید.

پیش از جایگزینی سراسری، نتیجه را بررسی کنید تا متن‌های ناخواسته تغییر نکنند.

| میان‌بر | کاربرد |

| `Ctrl + O` | باز کردن فایل |
| `Ctrl + S` | ذخیره فایل |

| `Ctrl + Z` | بازگردانی آخرین تغییر |

ممکن است میان‌برها بر اساس سیستم‌عامل یا تنظیمات شخصی تغییر کرده باشند.

## ۱۳. مدیریت چند فایل در یک پروژه

گزارش‌های کوچک را می‌توان در یک فایل TEX نوشت.

اما در پروژه‌های بزرگ‌تر ممکن است از چند فایل استفاده کنیم.

مثلاً:

```text
MyReport/
├── main.tex
├── introduction.tex
├── conclusion.tex
└── images/
    └── screenshot.png
```

در فایل اصلی می‌توان محتوای فایل‌های دیگر را وارد کرد:

```latex
\input{introduction}
\input{conclusion}
```

### دستور input چه می‌کند؟

این دستور محتوای فایل دیگر را در همان نقطه وارد سند می‌کند.

برای مثال:

```latex
\input{introduction}
```

یعنی محتوای فایل `introduction.tex` در سند اصلی قرار می‌گیرد.

### نکته مهم درباره فایل اصلی

در پروژه‌های چندفایلی، معمولاً باید فایل `main.tex` را به‌عنوان سند اصلی پردازش کنیم.

TeXstudio امکان مشخص کردن فایل اصلی یا **Root Document** را نیز دارد.

برای پروژه‌های ساده این آموزش، فعلاً همان فایل `main.tex` کافی است.

## ۱۴. قابلیت رفت‌وبرگشت بین کد و PDF

یکی از قابلیت‌های مفید TeXstudio، هماهنگی بین محل کد و خروجی PDF است.

این ویژگی معمولاً با نام **SyncTeX** شناخته می‌شود.

با فعال بودن تنظیمات مربوط، می‌توانید از بخش‌هایی از کد به محل متناظر در PDF بروید و در برخی حالت‌ها مسیر برعکس را هم انجام دهید.

این قابلیت مخصوصاً برای گزارش‌های چندصفحه‌ای بسیار کاربردی است.

---

## ۱۵. چند عادت خوب برای کار با TeXstudio

برای جلوگیری از مشکلات رایج:

1. برای هر گزارش یک پوشه مستقل بسازید.
2. فایل اصلی را `main.tex` نام‌گذاری کنید.
3. نام فایل‌ها را ترجیحاً انگلیسی و بدون فاصله انتخاب کنید.
4. پس از تغییرات مهم، فایل را ذخیره کنید.
5. بعد از اضافه کردن هر بخش، خروجی را بررسی کنید.
6. اگر خطایی ایجاد شد، ابتدا آخرین تغییرات را بررسی کنید.
7. تصاویر و فایل‌های موردنیاز را داخل پوشه پروژه نگه دارید.
8. از فایل‌های مهم نسخه پشتیبان تهیه کنید.

- [ ] یک بخش جدید با عنوان «مشخصات دانشجو» اضافه کنید.
- [ ] متن آن بخش را در PDF مشاهده کنید.
- [ ] عمداً دستور `\section` را اشتباه تایپ کنید.
- [ ] پیام خطا را مشاهده کنید.
- [ ] اشتباه را اصلاح کرده و دوباره PDF بگیرید.

### معیار موفقیت

اگر توانستید یک سند فارسی را ایجاد کنید، خروجی آن را مشاهده کنید و یک خطای ساده را برطرف کنید، این درس را با موفقیت گذرانده‌اید.
