# 🪟 درس ۱: نصب LaTeX و TeXstudio روی ویندوز

> سطح آموزش: مبتدی مطلق  
> سیستم‌عامل: Windows 10 / Windows 11  
> پیش‌نیاز: اتصال اینترنت برای نصب نرم‌افزارها و بسته‌های موردنیاز

## 🎯 در این درس چه یاد می‌گیریم؟

در پایان این آموزش می‌توانید:

- LaTeX را روی ویندوز نصب کنید.
- نرم‌افزار TeXstudio را اجرا کنید.
- موتور XeLaTeX را تنظیم کنید.
- اولین سند فارسی خود را بنویسید.
- از فایل خود خروجی PDF بگیرید.

---

## ۱. قبل از نصب، این سه مفهوم را بشناسیم

برای شروع، سه ابزار اصلی داریم:

**MiKTeX:** مجموعه‌ای از برنامه‌ها و بسته‌های لازم برای پردازش فایل‌های LaTeX است.

**TeXstudio:** نرم‌افزاری است که داخل آن کد LaTeX می‌نویسیم و فایل PDF را مشاهده می‌کنیم.

**XeLaTeX:** موتور پردازش فایل LaTeX است که برای نوشتن متن فارسی و استفاده از فونت‌های سیستم مناسب است.

به زبان ساده:

```text
نوشتن کد در TeXstudio
          |
          v
پردازش با XeLaTeX
          |
          v
تولید فایل PDF
```

نکته: TeXstudio به‌تنهایی برای تولید PDF کافی نیست؛ ابتدا باید یک توزیع LaTeX مانند MiKTeX نصب شود.

---

## ۲. دانلود و نصب MiKTeX

### مرحله اول: دانلود

به سایت رسمی MiKTeX مراجعه کنید:

https://miktex.org/download

در بخش Windows، گزینه **Basic MiKTeX Installer** را دانلود کنید.

بهتر است فایل نصب را از سایت رسمی دریافت کنید.

### مرحله دوم: اجرای نصب‌کننده

1. روی فایل دانلودشده دوبار کلیک کنید.
2. شرایط استفاده را مطالعه و تأیید کنید.
3. روی `Next` کلیک کنید.
4. در قسمت انتخاب کاربران، برای لپ‌تاپ شخصی می‌توانید گزینه نصب فقط برای کاربر فعلی را انتخاب کنید.
5. مسیر نصب پیش‌فرض را نگه دارید.
6. در صورت نمایش گزینه `Install missing packages on-the-fly`، مقدار `Yes` را انتخاب کنید.
7. مراحل نصب را تا پایان ادامه دهید.

ممکن است عنوان یا ترتیب برخی گزینه‌ها با نسخه نصب‌کننده متفاوت باشد.

### نصب خودکار بسته‌ها یعنی چه؟

فرض کنید در گزارش خود از بسته‌ای برای نمایش تصویر استفاده می‌کنید، اما آن بسته هنوز نصب نشده است.

MiKTeX می‌تواند هنگام پردازش سند، بسته موردنیاز را دانلود و نصب کند.

بنابراین لازم نیست از همان ابتدا تمام بسته‌های LaTeX را نصب کنید.

---

## ۳. تنظیم MiKTeX Console

بعد از نصب، از منوی Start ویندوز عبارت زیر را جست‌وجو کنید:

`MiKTeX Console`

برنامه را باز کنید.

### بررسی به‌روزرسانی‌ها

1. وارد بخش `Updates` شوید.
2. روی `Check for Updates` کلیک کنید.
3. اگر به‌روزرسانی وجود داشت، آن‌ها را نصب کنید.

### تنظیم نصب بسته‌های جدید

1. وارد `Settings` شوید.
2. تب `General` را باز کنید.
3. تنظیم نصب خودکار بسته‌های گمشده را پیدا کنید.
4. گزینه `Ask me` یا `Always install missing packages on-the-fly` را انتخاب کنید.

برای افراد مبتدی، `Ask me` مناسب است؛ زیرا هنگام نیاز به نصب بسته جدید از شما اجازه می‌گیرد.

---

## ۴. دانلود و نصب TeXstudio

حالا باید محیط نوشتن LaTeX را نصب کنیم.

### مرحله اول: دانلود

وارد سایت رسمی شوید:

https://www.texstudio.org/

نسخه Windows Installer متناسب با سیستم خود را دانلود کنید.

برای بیشتر لپ‌تاپ‌های معمولی با پردازنده Intel یا AMD، نسخه Windows x86_64 مناسب است.

### مرحله دوم: نصب

1. فایل نصب را اجرا کنید.
2. مراحل نصب را با تنظیمات پیش‌فرض ادامه دهید.
3. در پایان، TeXstudio را باز کنید.

اکنون محیطی برای نوشتن فایل‌های LaTeX در اختیار دارید.

---

## ۵. تنظیم موتور XeLaTeX

این مرحله برای نوشتن فارسی بسیار مهم است.

در TeXstudio:

1. از منوی بالا وارد `Options` شوید.
2. گزینه `Configure TeXstudio` را انتخاب کنید.
3. وارد بخش `Build` شوید.
4. در قسمت `Default Compiler` گزینه `XeLaTeX` را انتخاب کنید.
5. تنظیمات را با `OK` ذخیره کنید.

از این به بعد برای پردازش سند فارسی از XeLaTeX استفاده می‌کنیم.

> ⚠️ برای نمونه‌های فارسی این مجموعه از pdfLaTeX استفاده نکنید؛ تنظیمات و بسته‌های این آموزش برای XeLaTeX نوشته شده‌اند.

---

## ۶. ساخت اولین فایل LaTeX

حالا وقت اولین تمرین عملی است.

### مرحله اول: ساخت پوشه پروژه

در بخش Documents ویندوز، پوشه‌ای با نام زیر بسازید:

`MyFirstLaTeX`

پیشنهاد می‌شود برای شروع، نام پوشه‌ها و فایل‌های پروژه انگلیسی و بدون فاصله باشد.

### مرحله دوم: ایجاد فایل جدید

1. TeXstudio را باز کنید.
2. از منوی `File` گزینه `New` را بزنید.
3. کد زیر را در محیط ویرایشگر قرار دهید.

```latex
\documentclass[12pt,a4paper]{article}

\usepackage{xepersian}

\settextfont{Tahoma}
\setlatintextfont{Times New Roman}

\title{اولین گزارش من با لاتک}
\author{نام و نام خانوادگی دانشجو}
\date{\today}

\begin{document}

\maketitle

\section{مقدمه}

سلام!

این اولین سند فارسی من با لاتک است.

\section{هدف آزمایش}

هدف این تمرین، آشنایی با محیط لاتک
و تولید یک فایل PDF است.

\section{نتیجه‌گیری}

من توانستم اولین گزارش فارسی خود را ایجاد کنم.

\end{document}
```

### مرحله سوم: ذخیره فایل

از منوی `File` گزینه `Save As` را انتخاب کنید.

فایل را داخل پوشه `MyFirstLaTeX` با نام زیر ذخیره کنید:

`main.tex`

پسوند `.tex` نشان می‌دهد که فایل، کد منبع LaTeX است.

### مرحله چهارم: تولید PDF

1. مطمئن شوید کامپایلر روی `XeLaTeX` تنظیم شده است.
2. از نوار ابزار، دستور Build را اجرا کنید یا کلید `F5` را بزنید.
3. منتظر پایان پردازش بمانید.

اگر پردازش موفق باشد، فایل `main.pdf` در پوشه پروژه ایجاد می‌شود.

تبریک! 🎉 شما اولین فایل PDF فارسی خود را با LaTeX ساخته‌اید.

---

## ۷. ساختار کد را بفهمیم

لازم نیست فعلاً تمام دستورها را حفظ کنید.

| دستور | کاربرد |
|---|---|
| `\documentclass` | تعیین نوع سند و تنظیمات اولیه |
| `\usepackage{xepersian}` | فعال کردن پشتیبانی فارسی |
| `\settextfont` | انتخاب فونت فارسی |
| `\title` | تعیین عنوان سند |
| `\author` | تعیین نویسنده |
| `\date` | تعیین تاریخ |
| `\begin{document}` | شروع محتوای سند |
| `\maketitle` | نمایش عنوان، نویسنده و تاریخ |
| `\section` | ایجاد عنوان بخش |
| `\end{document}` | پایان سند |

هر چیزی که بین `\begin{document}` و `\end{document}` قرار می‌گیرد، بخشی از محتوای اصلی گزارش است.

---

## ۸. فایل‌های ایجادشده در پوشه پروژه

بعد از اجرای موفق LaTeX، ممکن است چند فایل ببینید:

```text
MyFirstLaTeX/
├── main.tex
├── main.pdf
├── main.log
└── main.aux
```

**main.tex:** فایل اصلی کدها؛ باید آن را نگه دارید.

**main.pdf:** خروجی نهایی قابل مشاهده و چاپ.

**main.log:** اطلاعات پردازش و خطاهای احتمالی.

**main.aux:** فایل کمکی موردنیاز LaTeX.

بسته به تنظیمات، فایل‌های کمکی دیگری هم ممکن است ایجاد شوند.

## ۹. خطاهای رایج هنگام نصب و اجرای اولین سند

### مشکل اول: دستور XeLaTeX پیدا نمی‌شود

اگر خطایی مانند زیر مشاهده کردید:

`Could not start the command: xelatex`

راه‌حل:

1. بررسی کنید MiKTeX کامل نصب شده باشد.
2. TeXstudio را ببندید و دوباره باز کنید.
3. در Command Prompt ویندوز بنویسید:

```cmd
xelatex --version
```

اگر نسخه XeLaTeX نمایش داده شد، برنامه در دسترس است.

اگر دستور شناسایی نشد، مسیر اجرایی MiKTeX در PATH ویندوز یا نصب آن را بررسی کنید.

### مشکل دوم: بسته xepersian پیدا نمی‌شود

ممکن است با خطای زیر مواجه شوید:

`File 'xepersian.sty' not found`

راه‌حل:

1. اینترنت را بررسی کنید.
2. MiKTeX Console را باز کنید.
3. در بخش `Packages` عبارت `xepersian` را جست‌وجو کنید.
4. در صورت نصب نبودن، آن را نصب کنید.
5. سند را دوباره پردازش کنید.

### مشکل سوم: فونت فارسی پیدا نمی‌شود

اگر خطایی مربوط به `Tahoma` مشاهده کردید:

1. مطمئن شوید فونت Tahoma در ویندوز نصب است.
2. نام فونت را دقیق بررسی کنید.
3. اگر از فونت دیگری استفاده می‌کنید، باید نام آن را در دستور `\settextfont` بنویسید.

### مشکل چهارم: PDF ساخته نمی‌شود

1. پایین محیط TeXstudio بخش خطاها را بررسی کنید.
2. به اولین خطای اصلی توجه کنید.
3. مطمئن شوید فایل ذخیره شده است.
4. بررسی کنید موتور پردازش `XeLaTeX` باشد.
5. از وجود `\begin{document}` و `\end{document}` مطمئن شوید.

نکته: اولین پردازش ممکن است به‌دلیل دانلود بسته‌های لازم بیشتر طول بکشد.
