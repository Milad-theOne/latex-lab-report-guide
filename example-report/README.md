# 📄 پروژه نمونه گزارش آزمایشگاهی فارسی با LaTeX

این پوشه شامل یک قالب آماده برای نوشتن گزارش آزمایشگاهی دانشگاه با **LaTeX، XeLaTeX و XePersian** است.

این نمونه برای دانشجویانی طراحی شده که تازه با LaTeX آشنا شده‌اند و می‌خواهند بدون ساخت قالب از صفر، اولین گزارش فارسی خود را بنویسند.

## 📁 ساختار پروژه

```text
example-report/
├── README.md
└── main.tex
```

فایل `main.tex` شامل صفحه عنوان، فهرست مطالب، بخش‌های گزارش، جدول، فرمول و نمونه نمایش دستورات ترمینال است.

برای اضافه کردن اسکرین‌شات‌های واقعی، می‌توانید پوشه `images` را نیز ایجاد کنید.

## ۱. پیش‌نیازها

برای اجرای این پروژه به موارد زیر نیاز دارید:

- یک توزیع LaTeX مانند MiKTeX در ویندوز یا TeX Live در لینوکس
- موتور پردازش XeLaTeX
- بسته XePersian
- ویرایشگر TeXstudio یا ویرایشگر سازگار دیگر
- حداقل یک فونت فارسی مناسب، مانند Amiri یا Tahoma

برای نصب ابزارها، به راهنماهای زیر مراجعه کنید:

- [نصب LaTeX در ویندوز](../docs/01-installation-windows.md)
- [نصب LaTeX در اوبونتو](../docs/02-installation-linux.md)
- [آشنایی با TeXstudio](../docs/03-texstudio.md)

## ۲. اجرای پروژه

### مرحله اول: دریافت فایل‌ها

مخزن را از GitHub دریافت کنید.

می‌توانید از گزینه `Code → Download ZIP` استفاده کنید و سپس ZIP را استخراج کنید.

یا در صورت نصب بودن Git، مخزن را Clone کنید.

### مرحله دوم: باز کردن فایل

وارد پوشه `example-report` شوید.

فایل `main.tex` را با TeXstudio باز کنید.

### مرحله سوم: انتخاب XeLaTeX

از مسیر زیر وارد تنظیمات شوید:

`Options → Configure TeXstudio → Build`

موتور پردازش را روی `XeLaTeX` تنظیم کنید.

### مرحله چهارم: تولید PDF

فایل را ذخیره کنید و با کلید `F5` آن را پردازش کنید.

برای کامل شدن فهرست مطالب و ارجاع‌ها، معمولاً باید دو بار XeLaTeX را اجرا کنید.

اگر پردازش موفق باشد، فایل `main.pdf` تولید می‌شود.

## ۳. تغییر مشخصات گزارش

در فایل `main.tex` بخش `Report information` را پیدا کنید.

در آن قسمت، مشخصات نمونه به این صورت تعریف شده‌اند:

```latex
\newcommand{\universityname}{دانشگاه نمونه}
\newcommand{\coursename}{آزمایشگاه سیستم‌عامل}
\newcommand{\reporttitle}{آشنایی با محیط لینوکس}
\newcommand{\experimentnumber}{آزمایش اول}
\newcommand{\studentname}{نام و نام خانوادگی}
\newcommand{\studentid}{۱۴۰۳۰۰۰۰۰۰۰}
\newcommand{\professorname}{نام استاد}
\newcommand{\submissiondate}{۱۴۰۵/۰۷/۲۷}
\newcommand{\academicyear}{۱۴۰۵--۱۴۰۶}
```

فقط متن داخل آکولاد دوم هر دستور را متناسب با اطلاعات خودتان تغییر دهید.

برای مثال:

```latex
\newcommand{\studentname}{علی رضایی}
```

**توجه:** نام دستورها را تغییر ندهید؛ چون در قسمت‌های دیگر فایل استفاده شده‌اند.

## ۴. تغییر محتوای آزمایش

متن گزارش نمونه صرفاً برای آموزش است.

بخش‌های اصلی آن عبارت‌اند از:

1. مقدمه
2. هدف آزمایش
3. ابزارهای موردنیاز
4. مراحل انجام آزمایش
5. نتایج و مشاهدات
6. نمونه فرمول ریاضی
7. اضافه کردن تصویر
8. مشکلات و راه‌حل‌ها
9. نتیجه‌گیری

می‌توانید عنوان‌ها و متن‌ها را مطابق آزمایش واقعی خودتان تغییر دهید.

**نتایج نمونه را جایگزین مشاهدات واقعی آزمایش کنید.** متن آماده به‌تنهایی نشان‌دهنده انجام آزمایش نیست.

## ۵. اضافه کردن تصاویر

ابتدا پوشه‌ای به نام `images` در کنار فایل `main.tex` بسازید.

ساختار پروژه:

```text
example-report/
├── README.md
├── main.tex
└── images/
    └── terminal.png
```

سپس در بخش تصاویر فایل `main.tex`، علامت‌های `%` ابتدای خطوط نمونه تصویر را حذف کنید.

کد فعال‌شده باید به این شکل باشد:

```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[
        width=0.85\textwidth
    ]{images/terminal.png}
    \caption{خروجی ترمینال}
    \label{fig:terminal}
\end{figure}
```

**مهم:** قبل از فعال کردن این کد، تصویر `terminal.png` باید واقعاً در پوشه `images` وجود داشته باشد.

راهنمای کامل: [کار با تصاویر و اسکرین‌شات‌ها](../docs/05-images.md)

## ۶. فونت‌های ویندوز و لینوکس

قالب نمونه تلاش می‌کند فونت فارسی را از بین گزینه‌های زیر انتخاب کند:

1. Amiri
2. Tahoma
3. DejaVu Sans

اگر هیچ‌کدام موجود نباشند، لازم است یک فونت مناسب نصب کنید یا تنظیمات فونت را در `main.tex` تغییر دهید.

در اوبونتو می‌توانید فونت Amiri را نصب کنید:

```bash
sudo apt update
sudo apt install fonts-hosny-amiri
```

برای بررسی شناسایی فونت:

```bash
fc-match Amiri
```

**توجه:** خروجی `fc-match` ممکن است یک فونت جایگزین باشد. برای اطمینان از نصب خود Amiri، نام فونت انتخاب‌شده را بررسی کنید.

## ۷. اجرای پروژه با ترمینال

در اوبونتو می‌توانید از ترمینال نیز استفاده کنید.

ابتدا وارد پوشه پروژه شوید:

```bash
cd example-report
```

اگر از قبل داخل مخزن قرار ندارید، باید ابتدا به مسیر واقعی آن بروید.

سپس:

```bash
xelatex -halt-on-error main.tex
xelatex -halt-on-error main.tex
```

اگر پردازش موفق باشد، فایل `main.pdf` ایجاد می‌شود.

## ۸. آماده‌سازی پروژه برای تحویل

اگر استاد فایل‌های منبع را نیز درخواست کرده، معمولاً باید موارد زیر را تحویل دهید:

- فایل `main.tex`
- فایل PDF نهایی
- تمام تصاویر استفاده‌شده
- سایر فایل‌های وابسته، در صورت وجود

بهتر است قبل از ارسال ZIP، آن را در یک پوشه جداگانه استخراج و دوباره پردازش کنید.

راهنمای کامل: [خروجی PDF و ساخت ZIP](../docs/07-delivery.md)

## ۹. رفع مشکلات رایج

اگر PDF ساخته نمی‌شود:

- موتور پردازش را بررسی کنید.
- از نصب بودن XePersian مطمئن شوید.

راهنمای کامل: [عیب‌یابی LaTeX](../docs/08-troubleshooting.md)
