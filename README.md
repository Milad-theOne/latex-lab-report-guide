# 📘 آموزش LaTeX از صفر تا گزارش‌نویسی دانشگاهی

### راهنمای فارسی و قدم‌به‌قدم برای دانشجویان

به این مخزن خوش آمدید! 👋

اگر تا امروز با **LaTeX** کار نکرده‌اید و نمی‌دانید چطور یک گزارش آزمایشگاهی مرتب و حرفه‌ای بنویسید، این آموزش برای شماست.

در این مجموعه یاد می‌گیریم چگونه LaTeX را روی کامپیوتر شخصی نصب کنیم، اولین سند خود را بسازیم، متن فارسی بنویسیم و در نهایت یک گزارش کامل دانشگاهی را به PDF تبدیل کنیم.

> 🎯 **هدف:** هر دانشجو بتواند بدون نیاز به دانش قبلی، گزارش آزمایشگاه خود را با LaTeX آماده و تحویل دهد.

---

## 🧩 LaTeX چیست؟

LaTeX یک سیستم حروف‌چینی و آماده‌سازی اسناد است که برای نوشتن گزارش‌های علمی، مقاله‌ها، پایان‌نامه‌ها و متن‌های دارای فرمول کاربرد زیادی دارد.

برخلاف Microsoft Word، در LaTeX معمولاً به‌جای تنظیم مستقیم ظاهر صفحه، دستورهایی می‌نویسیم و نرم‌افزار خروجی نهایی را تولید می‌کند.

**چرا LaTeX یاد بگیریم؟**

- 📐 نوشتن فرمول‌های ریاضی با کیفیت بالا
- 📑 ساخت فهرست مطالب و شماره‌گذاری خودکار
- 🖼️ مدیریت تصاویر، جدول‌ها و ارجاعات
- 🌐 پشتیبانی از زبان فارسی و انگلیسی
- 🎓 مناسب برای گزارش‌های دانشگاهی و متون علمی
- 🆓 رایگان و قابل استفاده در ویندوز و لینوکس

---

## 🛠️ ابزارهایی که استفاده می‌کنیم

| ابزار | کاربرد |
|---|---|
| MiKTeX | توزیع LaTeX برای ویندوز |
| TeX Live | توزیع LaTeX برای لینوکس |
| TeXstudio | محیط نوشتن و ویرایش فایل‌های LaTeX |
| XeLaTeX | موتور پردازش سند، مناسب برای متن فارسی |
| XePersian | بسته پشتیبانی از حروف‌چینی فارسی |

تمام آموزش‌ها بر اساس **نصب و اجرای LaTeX روی کامپیوتر شخصی** نوشته شده‌اند.
